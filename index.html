📜 Reglas — HexaSort Party v2

Objetivo: Acumula el mayor puntaje colocando pilas de hexágonos en el tablero compartido.

Tablero: 19 hexágonos compartidos por todos los jugadores.

Pool: 3 pilas de colores aleatorios (1-7 hexágonos cada una). Al colocar las 3, salen 3 nuevas.

Turnos: Los jugadores se turnan para colocar UNA pila del pool. El orden de selección rota cada ronda.

Merge (fusión):

  • Colocas una pila en una celda vacía.
  • Si tiene vecinos adyacentes del mismo color → los hexágonos de ese color se mueven a tu pila.
  • Si el merge crea nuevos adyacentes del mismo color → ¡encadena! (cascade)
  • Se prioriza el camino que acumule más hexágonos.

Desaparición: Cuando una pila acumula ≥10 hexágonos del mismo color → desaparecen. Cada hexágono = +1 punto.

Penalización: Si no hay dónde colocar → TODOS pierden 5 puntos, tablero se reinicia.

Victoria: Mayor puntaje tras las rondas configuradas. Desempate: menos hexágonos en tablero.
